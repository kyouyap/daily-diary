# Screen Timeの既存出力

既存の15分間隔収集を維持する。再インストール・Agent登録・権限変更・収集コマンド実行は日記資料の読取に含めない。DBへ書き込まず、日記用には既存のexports/current.jsonから一世代を固定して読む。

[再現手順](../../../docs/collection/setup.md)で確認済み構成を参照する。`scripts.activity_collection.sources.read_screentime_export(export_root, start, end)` はcurrent.jsonの世代名・タイムゾーン・JSON/CSVのハッシュを検証し、端末・アプリ別の日別秒数だけを返す。生セッションは呼出元へ返さない。ディスクからの読取と集計をローカルプロセスで行い、その生ログをCodexの入力へ出さない。

返ったusage記録のevent_timeは日精度、dataは端末・アプリ・利用秒数・世代・ハッシュ。日跨ぎは日本時間の0時で分割し、同一端末・アプリの重複区間を二重加算しない。端末を横断した総和を本人の実時間としない。

固定世代が削除された、ハッシュが違う、権限がない場合は失敗として残す。汎用Pythonで権限エラーなら権限を自動追加せず、確認済み専用Pythonを使えるか判断する。表示された集計の存在だけではiPhone同期の完全性を証明できない。ソースの欠落・同期遅延を確認できない期間を全件取得としない。
