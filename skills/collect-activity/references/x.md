# Xの本人投稿を読む

ログイン済みChromeのブラウザ操作だけを使う。現在の接続を確認し、最初に選択中のアカウントを記録する。configで指定されたアカウントごとに切り替え、プロフィールの識別子と照合する。URL・表示名だけで非公開アカウントの本人を判定しない。

通常投稿と本人の返信を確認し、日付・投稿URLからID・著者・本文を読む。長文は全文を展開する。省略のままなら部分取得とする。返信一覧に混在する相手の発言は本人投稿に含めない。

| kind | 入れる内容 |
|---|---|
| post | author_idは対象本人、textは本人本文 |
| reply | author_idは対象本人、textは本人本文、reply_to_idは返信先ID |
| quote | author_idとtextは本人。original_id・original_author_id・original_textは引用元として分離 |
| repost | external_idは元投稿ID、author_idとtextは元投稿。event_timeは共有日時、content_timeは元投稿日時 |

画面にない引用元本文を補完しない。引用先・返信先の追加巡回、画像・動画の保存はしない。共有日時不明のrepostはevent_timeをunknown/nullとして、初めて観測した日のJSONに保存する。古い元投稿だからといって捨てず、元投稿日時を共有日時として使わない。賛同・本人の意図をdataへ書かない。

対象期間の境界へ到達したことと、対象の投稿種別をどこまで確認したかを残す。追加読み込みが止まった、全文が出ない、種類の一部しか読めない場合はpartial。並び替え・固定投稿・返信スレッドがあるため、古い投稿を一件見つけただけで全件取得としない。共有日時不明のリポスト一覧から期間全体のcoverageを断定しない。

別アカウントのログイン切れはその対象だけ保留して続ける。終わったら元のアカウントへ戻し、識別子で確認する。復帰できなければその状態を報告し、以後の対象を取り違えない。
