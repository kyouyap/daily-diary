# YouTubeの再生履歴

ログイン済みChromeで、設定済みの一チャンネルを照合してから `https://www.youtube.com/feed/history` を読む。YouTube Musicの履歴には移動しない。再生を開始せず、履歴のタイトル・URLからID・チャンネル・日付区分・Shorts等を読む。

一覧の「今日」「昨日」「曜日」は読取時点の日本時間で解釈し、画面のタイムゾーンを確認できなければ確定しない。日付区分しか分からなければprecision=day。動画の長さとURLのt=値を視聴時間や再生日時へ変換しない。

必要なら画面の「すべての履歴を管理」からGoogleの管理画面へ移動し、同じアカウントを照合する。検索・投稿閲覧が混在するので、再生した記録だけを読む。分単位の時刻があればminuteと元の表示を残す。設定変更、履歴の削除・停止、検索履歴の保存はしない。

kind=playback、external_id=動画ID、data.title=動画名、data.channel=チャンネル名。event_timeは見えた精度の日時。区別できる複数の再生日時はdata.observed_playback_timesへ入れ、動画IDだけで別日の履歴を消さない。同日・同動画の時刻なし重複から再生回数を作らない。

対象期間と一覧の追加読み込みを確認する。日付境界の一部しか読めない、次ページが不明、表示遅延の案内があるなどの場合は、確実な範囲だけcoverageにし残りはpartialとして残す。「画面に記録がない」と「対象期間を全部調べて記録がない」を区別する。初版の全件取得と同日反復の網羅性は実機未検証。
