# Daily diary

自分がその日に行ったタスクを、仕事・個人開発・その他に分けてNotionへ残すCodexスキルです。個人開発では、自分の判断・貢献・結果を整理する練習も兼ねます。

## 使い方

```text
$daily-diary 今日の業務日誌をまとめて
```

日付指定がなければ、日本時間の今日0時から実行時点までを対象にします。

1. Langfuseの全会話、メール、PC活動記録を読み、課題・目的ごとにタスクを整理する。
2. ログに残らない活動を質問し、必要に応じて一問ずつ話を広げる。
3. 保存する全文を表示し、本人のOKを受ける。
4. Notionへ保存して読み戻し、日誌のリンクを返す。

取得できない資料は欠落を伝え、本人の補足と全文確認があれば保存できます。同日の追記は既存本文と本人の編集を保ち、統合した全文を確認します。

一日一ページ。ページ名は日付だけ、DB項目はタイトルと日付だけ。本文の出典・記録範囲は末尾の折りたたみに置きます。日誌本文・生ログ・資格情報はGitへ保存しません。
